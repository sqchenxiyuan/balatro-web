**后续实施说明：** 本文覆盖矩阵与待验收清单记录的是玩法改版前的样片状态。用户随后明确“默认全解锁、不做局外成长”；因此资料档解锁计数、收藏成长与通关解锁不是实施目标。已完成的单局初版、当前覆盖和测试证据统一见 [20：玩法复刻初版](20-first-playable.md)。本文保留来源和历史缺口供核对。

## 7. 后续实现的验收场景

以下是**待执行验收**，不是本轮已通过的运行测试：

1. 首个小盲获胜 → Cash Out → 首店；默认两商品、两包、一券，首店含普通丑角包。
2. 普通商品刷新只替换商品；券按 Ante 更新；已买包不被一次刷新复活。
3. 二级券不设资料档门槛；分别验证本局未兑换基础券时不进入池、兑换基础券后可出现。
4. 黑色牌组减少出牌次数，彩绘牌组增加手牌上限；显示与 API 字段不混用。
