# 增强、版本、蜡封与补充包

调研日期：2026-11-07。以下为公开社区 Wiki 的事实表转录，保留英文名称用于稳定检索；不是原版运行验证。每条 JSON 记录包含来源 URL、页面修订号、表号和行号（表号、行号从 0 开始）。

## 增强：8 种

来源：[Card modifiers](https://balatrowiki.org/w/Card_modifiers)。

| 名称 | 效果 |
| --- | --- |
| Bonus Card | +30 extra chips |
| Mult Card | +4 Mult |
| Wild Card | Can be used as any suit |
| Glass Card | X2 Mult 1 in 4 chance to destroy card |
| Steel Card | X1.5 Mult while this card stays in hand |
| Stone Card | +50 Chips no rank or suit |
| Gold Card | $3 if this card is held in hand at end of round |
| Lucky Card | 1 in 5 chance for +20 Mult 1 in 15 chance to win $20 |

## 蜡封：4 种

来源：[Card modifiers](https://balatrowiki.org/w/Card_modifiers)。

| 名称 | 效果 |
| --- | --- |
| Gold Seal | Earn $3 when this card is played and scores |
| Red Seal | Retrigger this card 1 time |
| Blue Seal | Creates the Planet card for final played poker hand of round if held in hand (Must have room) |
| Purple Seal | Creates a Tarot card when discarded (Must have room) |

## 版本：含基础版共 5 种

来源：[Card modifiers](https://balatrowiki.org/w/Card_modifiers)。

| 名称 | 效果 |
| --- | --- |
| Base | No extra effects |
| 闪箔 Foil | +50 Chips |
| 镭射 Holographic | +10 Mult |
| 多彩 Polychrome | X1.5 Mult |
| 负片 Negative | +1 Joker or Consumable slot |

2026-11-08 补核中文名称：原版简体中文使用“镭射”，没有独立的“全息”条目。依据各 Wiki 版本条目的 “In other languages” 表；“全息”和“箔片”仅是旧 demo 用词，不作为正式条目名称。版本、增强、蜡封是三个独立类别，玻璃属于增强。
